Comment faire

  1. Téléchargez le modèle : trois feuilles, Propriétaires, Bâtiments et Lots.
  2. Recopiez-y le patrimoine, une ligne par fiche. La feuille « Lisez-moi » donne les valeurs admises.
  3. Déposez le fichier : il est contrôlé en entier, sans rien enregistrer.
  4. S'il n'y a plus d'erreur, confirmez l'import.

Un même fichier peut être déposé plusieurs fois : les fiches déjà présentes sont reconnues par leur nom et ne sont pas dupliquées.
