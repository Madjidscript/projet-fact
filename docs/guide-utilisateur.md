# Guide d'utilisation — FACT Immobilier

Ce guide explique, démarche par démarche, comment se servir de l'application de gestion de FACT Immobilier, de l'application de terrain sur téléphone, de l'espace propriétaire et du site internet.

Chaque démarche dit **qui** peut la faire, puis **comment**, étape par étape. Les mots entre guillemets « … » sont ceux des boutons et des menus de l'application.

## 1. Premiers pas

### Se connecter

1. Ouvrez l'adresse de l'application dans votre navigateur (Chrome, Edge, Firefox ou Safari).
2. Saisissez votre **identifiant** (un propriétaire peut aussi saisir son **adresse e-mail**) et votre **mot de passe**.
3. Touchez « Se connecter ».

À la **première connexion**, l'application demande de remplacer le mot de passe provisoire remis par l'agence. Choisissez un mot de passe que vous seul connaissez.

> Après cinq mots de passe erronés en dix minutes, la connexion depuis cet appareil est bloquée cinq minutes, par sécurité. Attendez, puis réessayez, ou demandez à l'administrateur.

### Changer son mot de passe

Menu de gauche (ou « Plus » sur téléphone) → votre nom en bas → « Changer de mot de passe ».

### Se repérer dans l'écran

- **Sur ordinateur** : le menu est à gauche. On peut le replier pour gagner de la place.
- **Sur tablette** : le menu ne montre que les pictogrammes ; touchez-le pour le déplier.
- **Sur téléphone** : une barre en bas donne les quatre rubriques principales ; « Plus » ouvre les autres.
- La **cloche** montre les alertes qui vous concernent (voir chapitre 3).
- Le bouton **lune / soleil** passe du thème clair au thème sombre.

### Se déconnecter

En bas du menu : « Se déconnecter ». Faites-le toujours sur un ordinateur partagé.

## 2. Qui voit quoi : les profils

Chaque compte a un **profil**. Le profil décide des menus visibles et de ce que l'on peut modifier.

| Profil | Rôle | Ce qu'il voit |
|---|---|---|
| **Direction** | Vue d'ensemble, décisions | Tout le patrimoine, tous les indicateurs ; réaffecte les bâtiments, valide les annonces, ouvre les espaces propriétaires |
| **Gestionnaire** | Suit un portefeuille de bâtiments | Ses bâtiments (ceux dont il est gestionnaire ou suppléant), leurs locataires, loyers et travaux ; prépare les tournées |
| **Agent de terrain** | Visites, recensements, états des lieux, encaissements | L'application de terrain sur téléphone |
| **Responsable travaux** | Traite les pannes et les chantiers | Les interventions, les prestataires, la validation des devis |
| **Éditeur web** | Contenu du site | Les annonces à valider, les demandes des visiteurs |
| **Administrateur** | Comptes et réglages | Tout, plus les comptes, l'import et le journal |
| **Propriétaire** | Mandant de l'agence | Son seul espace : ses biens, ses loyers, ses travaux, ses documents — jamais les noms ni les téléphones de ses locataires |

L'administrateur peut accorder un **droit en plus** à un compte (par exemple, permettre à un gestionnaire d'encaisser), sans changer son profil.

## 3. Le tableau de bord et les alertes

### Le tableau de bord

C'est la page d'accueil du personnel. Elle montre :

- les chiffres clés (bâtiments, lots, occupation, loyers, impayés) ;
- le bloc **« À traiter »** : ce qui demande une action aujourd'hui ;
- l'occupation des lots, les lots vacants par commune, les bâtiments avec le plus de lots libres.

Chaque chiffre est cliquable et mène à la liste correspondante.

### Les alertes (la cloche)

L'application prévient d'elle-même la bonne personne. Exemples :

| Alerte | Qui la reçoit |
|---|---|
| Bail arrivant à échéance, loyer en retard, lot vacant | Le gestionnaire du bâtiment |
| Mandat arrivant à échéance | La Direction |
| Panne urgente signalée | Le responsable travaux et le gestionnaire |
| Bâtiment sans gestionnaire | La Direction |
| Nouvelle demande du site, demande en attente | Le service concerné |
| Annonce à valider | La Direction, l'éditeur web |
| Bâtiment réaffecté | L'ancien et le nouveau gestionnaire |
| Devis à approuver | Le propriétaire concerné |
| Réponse du propriétaire à un devis | Le responsable travaux et le gestionnaire |
| Relevé mensuel disponible | Le propriétaire |
| Compte rendu de tournée | Les gestionnaires des bâtiments visités |

**Lire une alerte** : touchez la cloche, puis l'alerte ; l'application ouvre directement la fiche concernée. « Tout marquer comme lu » vide le compteur.

Les alertes se mettent à jour toutes les dix minutes, et immédiatement après les événements importants.

## 4. La carte

**Qui** : tous les profils qui lisent le patrimoine (le propriétaire ne voit que ses biens).

- Chaque bâtiment est un point sur la carte d'Abidjan.
- « Couleur des bâtiments » change ce que montrent les couleurs : **Occupation**, **Impayés**, **Travaux**, **Gestionnaire** ou **Validation**.
- Touchez un point pour voir le résumé du bâtiment, puis ouvrez sa fiche.
- « Ma position » centre la carte là où vous êtes.

### Placer ou corriger la position d'un bâtiment

**Qui** : gestionnaire, Direction, administrateur.

1. Ouvrez le bâtiment sur la carte.
2. Touchez « Déplacer », faites glisser le point au bon endroit (l'image satellite aide).
3. Touchez « Enregistrer la position ».

Les bâtiments importés sans coordonnées apparaissent dans la liste **« À localiser »** : un agent les place lors de son passage.

## 5. Les bâtiments et les lots

### Créer un bâtiment au bureau

**Qui** : gestionnaire, Direction, administrateur.

1. Menu « Bâtiments » → « Nouveau bâtiment ».
2. Renseignez le nom, le type, la commune, le quartier, un repère, le nombre de niveaux.
3. Choisissez le **propriétaire** (liste avec recherche) et le **gestionnaire**.
4. Placez le bâtiment sur la carte : un bâtiment ne peut pas être enregistré sans position ni propriétaire.
5. Enregistrez.

> Les longues listes (communes, quartiers, propriétaires, bâtiments…) ont toutes un champ de recherche : tapez quelques lettres.

### La fiche d'un bâtiment

Onglets : **Identité**, **Lots**, **Location**, **Interventions**, **Propriétaire**, **Historique** (toutes les modifications, avec qui et quand).

- « Vue par étage » montre les lots étage par étage, avec leur statut en couleur.
- Les **photos** prises sur le terrain s'affichent dans la fiche.
- « Modifier » change l'identité du bâtiment.

### Valider une fiche recensée sur le terrain

Un bâtiment créé depuis le téléphone arrive avec le statut **« À valider »**.

1. Ouvrez la fiche (alerte, ou filtre « À valider » de la liste des bâtiments).
2. Contrôlez la position, les photos, le propriétaire, les lots.
3. Corrigez si besoin, puis touchez « Valider la fiche ».

### Ajouter ou modifier un lot

1. Fiche du bâtiment → onglet « Lots » → « Ajouter un lot » (ou « Saisir le premier »).
2. Numéro de porte (unique dans le bâtiment), étage, type (Studio, F2, F3…), surface, loyer de référence.
3. Enregistrez. Pour modifier : ouvrez le lot → « Modifier le lot ».

**Statuts d'un lot** : Vacant · À louer / À vendre (publié sur le site) · Réservé · Occupé · En préavis · En travaux · Hors gestion.
Un lot **occupé** a toujours un bail actif ; un lot ne peut avoir qu'**un seul** bail actif.

### Archiver

Un bâtiment ou un propriétaire n'est jamais supprimé : il est **archivé** (Direction). Il reste consultable avec « Voir les archives ».

## 6. Les propriétaires et les mandats

### Créer ou modifier un propriétaire

**Qui** : gestionnaire, Direction, administrateur.

Menu « Propriétaires » → « Nouveau propriétaire » : type (personne physique ou société), nom, téléphones, **e-mail** (indispensable pour son espace en ligne), adresse, pièce d'identité, mode de reversement (mobile money, virement…) et coordonnées.

### Saisir un mandat

**Qui** : Direction.

1. Fiche du propriétaire → bloc « Mandat de gestion » → « Nouveau mandat ».
2. Type (gestion locative, mise en location, vente, syndic), date de début, durée, reconduction automatique ou non.
3. **Honoraires** (en % des loyers encaissés).
4. **Seuil de travaux** : au-delà de ce montant, un devis doit être accepté par le propriétaire. Vide = réglage général de l'agence (150 000 FCFA).
5. Biens couverts : tous ses bâtiments, ou certains seulement.

L'application prévient la Direction avant l'échéance. Pour arrêter un mandat : « Résilier », avec la date de fin et le motif.

### Déposer le mandat signé

Bloc du mandat → « Déposer le mandat signé » → choisissez le PDF ou la photo (10 Mo au plus). Le propriétaire le retrouve dans son espace.

### Le relevé de gestion du propriétaire

Fiche du propriétaire → bloc « Relevé de gestion » → choisissez « Du mois » et « Au mois » → « Voir les montants » ou « Relevé PDF ».
Le relevé montre les loyers encaissés, les honoraires, les travaux à sa charge et le montant à lui reverser, avec un plan de situation de ses biens.

### Ouvrir l'espace en ligne d'un propriétaire

**Qui** : Direction.

1. Vérifiez que la fiche du propriétaire porte son **e-mail**.
2. Fiche du propriétaire → bloc « Espace en ligne » → « Ouvrir son espace ».
3. L'écran affiche l'**identifiant** (son e-mail) et un **mot de passe provisoire**, une seule fois.
4. Touchez « Copier le message » et envoyez-le-lui par WhatsApp ou par e-mail.

Il changera le mot de passe à sa première connexion. « Voir son espace » vous montre son écran tel qu'il le voit.

## 7. Les locataires, les baux et les loyers

### Signer un bail

**Qui** : gestionnaire, Direction.

1. Ouvrez le lot (fiche du bâtiment → onglet « Lots », ou « Location »).
2. « Signer le bail ».
3. Locataire : « Déjà connu » (liste avec recherche) ou « Nouveau locataire » (nom, prénoms, téléphone, e-mail, pièce d'identité, profession, garant et son téléphone).
4. Date d'effet, durée, loyer mensuel, charges, caution, mois d'avance versés à l'entrée, jour du mois où le loyer est dû.
5. Enregistrez. Si une avance est versée, son encaissement et sa quittance sont créés d'office.

Le lot passe **« Occupé »** et son annonce est **retirée du site** automatiquement.

### Encaisser un loyer au bureau

**Qui** : gestionnaire, agent, administrateur (droit « encaisser »).

1. Ouvrez le lot → « Encaisser un loyer ».
2. Montant reçu, date du paiement, mode (espèces, mobile money, chèque, virement) et référence (n° de transaction, de chèque…).
3. « Enregistrer l'encaissement », puis « Ouvrir la quittance ».

L'application affecte le paiement aux mois dus, du plus ancien au plus récent. Si tout le mois est payé, le document est une **quittance de loyer** ; sinon, un **reçu de paiement** partiel.

### Annuler un encaissement erroné

**Qui** : Direction. Lot → « Encaissements » → la croix à côté du paiement → motif → « Annuler l'encaissement ». Le paiement reste visible, barré, avec son motif.

### Suivre les impayés

Menu « Loyers » : baux, derniers encaissements, recouvrement des six derniers mois. Le filtre « en retard » liste les locataires à relancer. L'échéancier du lot montre chaque mois : payé, partiel ou en retard.

### Préavis et sortie du locataire

1. Lot → « Préavis de départ » → date de sortie prévue, motif → « Enregistrer le préavis ». Le lot passe « En préavis ».
2. Le jour du départ : faites l'**état des lieux de sortie** (chapitre 9), puis lot → « Sortie du locataire » → date de sortie → « Enregistrer la sortie ». Le lot redevient vacant.

### Les états des lieux d'un lot

Fiche du lot → bloc « États des lieux » : la liste des états d'entrée et de sortie, avec le bouton du **PDF**. Ils se font sur place, depuis le téléphone (chapitre 9).

## 8. Les travaux

Le parcours d'une intervention : **Signalée → Prestataire choisi → En cours (constat et devis) → Devis validé → Travaux terminés → Clôturée**.

### Signaler une panne

**Qui** : tout le personnel qui suit les travaux, depuis le bureau ou le téléphone.

Menu « Travaux » (ou fiche du bâtiment) → « Signaler une panne » : bâtiment, lot, catégorie (plomberie, électricité…), urgence, description, photos de la panne. Une panne **urgente** déclenche une alerte immédiate.

### Gérer les prestataires

« Travaux » → « Nouveau prestataire » : nom ou entreprise, métier, téléphone, e-mail, notes (tarifs, disponibilités).

### Traiter une intervention

**Qui** : responsable travaux (et gestionnaire pour suivre).

1. « Affecter à un prestataire » : choisissez le prestataire et la date prévue.
2. Après le passage : « Enregistrer le constat » avec le montant du **devis**.
3. **Accord du propriétaire** : si le devis dépasse le seuil du mandat, le propriétaire reçoit une alerte et répond **en ligne** depuis son espace (accord, ou refus motivé). Vous pouvez aussi noter un accord obtenu par téléphone.
4. « Valider le devis » : impossible si le propriétaire a refusé — demandez alors un autre devis.
5. « Travaux terminés » : coût réel, photos après travaux.
6. « Clôturer » : à la charge du propriétaire, du locataire ou de l'agence.

## 9. L'application de terrain (téléphone)

### Installer l'application sur le téléphone

1. Ouvrez l'adresse de l'application dans le navigateur du téléphone et connectez-vous.
2. **Android** : touchez « Installer » dans le bandeau proposé.
   **iPhone** : touchez « Partager », puis « Sur l'écran d'accueil ».
3. L'icône FACT apparaît sur l'écran d'accueil ; l'application s'ouvre en plein écran et se met à jour toute seule.

> La position GPS et l'appareil photo demandent une autorisation la première fois : répondez « Autoriser ».

### Travailler sans réseau

Tout ce que vous saisissez est **gardé dans le téléphone**, puis envoyé tout seul au retour du réseau.

- Le bandeau orange « Hors connexion » signale l'absence de réseau.
- Le bouton rond en haut à droite compte les **saisies en attente** ; touchez-le pour les voir. « Envoyer maintenant » force l'envoi.
- Une saisie refusée par l'agence (par exemple, un état des lieux déjà fait) apparaît en rouge avec la raison : corrigez, ou supprimez-la.
- Un envoi interrompu puis repris **ne crée jamais de doublon**.

> Avant de partir sur le terrain, ouvrez l'application une fois avec du réseau : elle prend la liste à jour des bâtiments, des baux et de votre tournée.

### L'accueil du terrain

L'agent arrive directement sur l'accueil du terrain : sa **tournée du jour** (avec l'avancement), et quatre gestes — « Encaisser un loyer », « État des lieux », « Recenser un bâtiment », « Ma tournée ».

### La tournée du jour

1. « Ma tournée » : la carte trace l'itinéraire d'étape en étape, avec la distance et la durée estimées.
2. « Itinéraire depuis ma position » recalcule l'ordre de passage depuis l'endroit où vous êtes.
3. Pour chaque étape : le motif (recouvrement, état des lieux, contrôle, travaux, visite) et ce qu'il faut savoir.
4. « Y aller » ouvre le trajet dans Google Maps.
5. Sur place : « Je suis sur place ». Le téléphone affiche la **distance au bâtiment** (preuve du passage).
6. Choisissez le résultat : « Visite faite », « Personne » ou « Reportée », et écrivez ce que vous avez constaté (obligatoire si la visite n'a pas eu lieu).
7. Raccourcis : « Encaisser ici » et « État des lieux ici » ouvrent directement ce bâtiment.
8. « Valider le pointage ».
9. En fin de journée : écrivez le **compte rendu** de la tournée → « Terminer la tournée ». Les gestionnaires des bâtiments visités reçoivent une alerte.

**Pas de tournée prévue ?** L'écran propose les bâtiments à visiter en priorité (loyers en retard, états des lieux à faire, fiches à contrôler, travaux urgents). Cochez-les → « Préparer ma tournée » : l'ordre de passage est calculé pour vous (réseau nécessaire).

### Encaisser un loyer sur place

1. « Encaisser un loyer » → choisissez le **bâtiment** (le nombre de locataires en retard est indiqué).
2. Touchez le **lot** du locataire : ses retards s'affichent.
3. Montant reçu (raccourcis « 1 mois » et « Tout l'impayé »), mode de paiement, et pour le mobile money le **n° de transaction** (obligatoire).
4. « Envoyer le reçu au locataire » est coché d'office s'il a un téléphone.
5. « Encaisser », relisez le résumé avec le locataire → « Confirmer ».

Le reçu part au locataire par **WhatsApp** (et par e-mail s'il en a un), avec un lien qui ouvre sa quittance, sans compte. Sans réseau, tout part au retour du réseau.

### Faire un état des lieux

1. « État des lieux » → bâtiment → lot. Les pastilles disent si l'entrée et la sortie sont déjà faites.
2. Choisissez **Entrée** ou **Sortie**.
3. **Pièces** : la liste est proposée selon le type du lot (séjour, chambres, cuisine, salle de bain, WC…). Ajoutez ou retirez des pièces.
4. Pour chaque pièce, touchez l'état de chaque élément : **Bon**, **Usé**, **Mauvais**, **H.S.** (hors service). « Tout est bon » remplit d'un coup ce qui reste. Un état « Mauvais » ou « H.S. » ouvre une ligne pour décrire le défaut.
5. Prenez des **photos** par pièce ; ajoutez une remarque si besoin.
6. **Compteurs** : index d'eau (SODECI) et d'électricité (CIE), nombre de clés, observations générales.
7. **Signatures** : relisez ensemble, faites signer l'occupant **avec le doigt**, puis signez pour l'agence. « Effacer » permet de recommencer une signature.
8. « Enregistrer l'état des lieux ».

L'agence produit le **PDF** (fiche du lot → « États des lieux »). À la sortie, le PDF met en regard l'état noté à l'entrée.
Il n'y a qu'**un** état des lieux d'entrée et **un** de sortie par bail.

### Recenser un bâtiment

1. « Recenser un bâtiment ».
2. **Position** : devant l'entrée, touchez « Ma position ». La précision s'affiche (bonne, correcte ou faible) ; ajustez le point sur l'image satellite si besoin.
3. **Photos** : façade, entrée, rue.
4. **Bâtiment** : nom (ou ce qui est écrit sur la façade), type, commune, quartier, repère, niveaux, propriétaire (« à préciser » si vous ne le connaissez pas), observations.
5. **Lots** : pour un immeuble régulier, indiquez les niveaux et les portes par niveau → « Créer N lots », puis corrigez ce qui diffère (Occupé, Libre, Travaux).
6. « Enregistrer ». La fiche arrive **« À valider »** chez le gestionnaire.

La saisie en cours est gardée si le téléphone se ferme.

## 10. Les tournées, côté bureau

**Qui** : gestionnaire, Direction.

### Préparer la tournée d'un agent

1. Menu « Tournées » → « Préparer une tournée ».
2. Choisissez l'**agent** et le **jour** ; ajoutez une consigne si besoin.
3. Cochez les bâtiments **« À visiter en priorité »** (avec la raison : retards, états des lieux à faire…), ou « Ajouter un bâtiment ».
4. Ajustez le **motif** de chaque étape.
5. « Enregistrer la tournée ». L'ordre de passage le plus court depuis l'agence est calculé.

Un agent n'a qu'une tournée par jour ; la préparer à nouveau la modifie (les étapes déjà pointées restent).

### Suivre une tournée

La page « Tournées » montre, jour par jour, chaque tournée avec son avancement. Touchez-en une : la carte de l'itinéraire, chaque étape avec l'heure du pointage, la **distance au bâtiment** (signalée « loin » au-delà de 250 m) et le compte rendu de l'agent.

## 11. Les portefeuilles des gestionnaires

**Qui** : Direction (lecture : gestionnaires).

Menu « Portefeuilles » : chaque gestionnaire avec ses bâtiments sur la carte, en couleur.

### Réaffecter des bâtiments (congé, départ, rééquilibrage)

1. Sélectionnez les bâtiments (sur la carte ou dans la liste).
2. « Réaffecter » → choisissez le « Nouveau gestionnaire » et, si besoin, un « Nouveau suppléant » (sinon chaque bâtiment garde le sien) ; indiquez le motif (départ, congé, nouvelle répartition…).
3. « Confirmer la réaffectation ». Les bâtiments prennent la couleur du nouveau gestionnaire ; les deux gestionnaires sont prévenus.

« Historique des réaffectations » garde la trace de chaque changement.

## 12. Les annonces du site

### Publier un lot sur le site

**Qui** : gestionnaire (proposition), Direction ou éditeur web (validation).

1. Ouvrez le lot vacant → « Publier sur le site ».
2. « À louer » ou « À vendre », titre de l'annonce, prix, charges, caution et avance (en mois), description, **photos**.
3. Envoyez : l'annonce part **« À valider »**.
4. La Direction ou l'éditeur web la relit → « Valider et mettre en ligne » (ou la renvoie avec un motif).

### Retirer une annonce

« Annonces » → l'annonce → « Retirer ». Elle est aussi retirée **automatiquement** quand un bail est signé sur le lot.

Quand une annonce est mise en ligne, les visiteurs abonnés à une recherche correspondante sont prévenus (voir chapitre 13, « Messages à envoyer »).

## 13. Les demandes des visiteurs et les messages à envoyer

### Traiter une demande

**Qui** : Direction, éditeur web, gestionnaires selon les droits.

Les visiteurs du site envoient des demandes : visite d'un bien, confier un bien, devis de travaux, estimation, contact.

1. Menu « Demandes » : filtres « Nouvelles », « En cours », « Closes ».
2. Ouvrez une demande : coordonnées, bien concerné, pièces jointes éventuelles.
3. « Suivi » : passez-la **Prise en charge**, fixez un **rendez-vous** (date et heure), puis **Conclue** ou **Sans suite**. Notez ce qui a été dit dans la note interne → « Enregistrer le suivi ».

Une demande sans réponse pendant les heures ouvrées déclenche une alerte.

### Les messages à envoyer

En attendant les comptes d'envoi automatique (e-mail, SMS, WhatsApp), l'application **prépare** les messages : accusés de réception des demandes, alertes « nouveau bien » aux abonnés, relevés des propriétaires, **reçus de paiement** aux locataires.

1. « Demandes » → « Messages à envoyer ».
2. Chaque message a un bouton qui ouvre WhatsApp ou la messagerie avec le texte déjà rédigé.
3. Une fois envoyé, touchez « Envoyé » ; « Inutile » l'écarte.

## 14. Les rapports

**Qui** : Direction, gestionnaires (sur leur périmètre).

Menu « Rapports » : choisissez la période (« Du mois », « Au mois »).

- Occupation, durée de vacance, loyer moyen au m² (par quartier, par type de lot).
- Loyers attendus et réglés mois par mois, taux de recouvrement.
- Impayés par ancienneté, les plus gros retards.
- Délai de traitement des pannes, par catégorie et par prestataire.
- Demandes reçues par le site.

Les boutons « Excel » et « PDF » exportent le tableau de bord de la période.

## 15. L'espace propriétaire

**Qui** : le propriétaire, une fois son espace ouvert par la Direction (chapitre 6).

Il se connecte avec son **adresse e-mail** et arrive sur « Mon espace » :

- ses chiffres : bâtiments, taux d'occupation, loyers réglés sur 12 mois, impayés ;
- **les devis qui attendent sa réponse** : « Donner mon accord » ou « Refuser » (en disant pourquoi) ; l'agence est prévenue tout de suite ;
- **ses biens** sur une carte (vert : loué et payé, orange : lots à louer, rouge : loyers en retard), et lot par lot ;
- les loyers des 12 derniers mois en graphique ;
- les travaux en cours et terminés ;
- **ses documents** : relevé de gestion en PDF pour les mois choisis, et le mandat signé ;
- le contact de son gestionnaire : « Appeler », « WhatsApp », « E-mail ».

Le propriétaire ne voit **jamais** les noms ni les téléphones de ses locataires. Les pages de l'agence lui sont fermées.

## 16. Le site internet, côté visiteur

Le site public présente l'agence et ses biens. Un visiteur peut :

- **chercher un bien** à louer ou à acheter (commune, quartier, type, prix, nombre de pièces), sur la liste ou sur la carte ;
- ouvrir la **fiche d'un bien** : photos, prix, caractéristiques, quartier approximatif ;
- **demander une visite** depuis la fiche ;
- garder des biens en **favoris** (sur son appareil) ;
- créer une **alerte** : il est prévenu quand un nouveau bien correspond à sa recherche (lien de désabonnement dans chaque message) ;
- **confier son bien** à l'agence, demander un **devis de travaux** (avec pièces jointes : plans, photos), une **estimation**, ou écrire au **contact**.

Chaque demande arrive dans « Demandes » (chapitre 13), et le visiteur reçoit un accusé de réception.

> Le paiement en ligne n'est pas proposé pour le moment.

## 17. Administration : comptes, import, journal

### Créer un compte

**Qui** : administrateur.

1. Menu « Comptes » → « Nouveau compte ».
2. Identifiant, nom, fonction, e-mail, téléphone, **profil**, et droits supplémentaires éventuels.
3. Enregistrez : le **mot de passe provisoire** s'affiche une seule fois → notez-le et remettez-le à la personne → « J'ai noté le mot de passe ».

- « Modifier » change le profil, les droits ou les coordonnées.
- « Réinitialiser » donne un nouveau mot de passe provisoire (mot de passe oublié).
- « Désactiver » suspend le compte ; « Réactiver » le rouvre. Un compte n'est jamais supprimé : son historique reste.

### Importer le patrimoine existant

**Qui** : administrateur.

Menu « Import » : chargez le fichier Excel de l'agence (bâtiments, propriétaires, lots). « Comment faire » explique les colonnes attendues. À la fin :

- les bâtiments importés sont **« À valider »** par leur gestionnaire ;
- ceux sans coordonnées attendent le passage d'un agent (liste « À localiser ») ;
- la Direction affecte ensuite chaque bâtiment à son gestionnaire (chapitre 11).

### Le journal

**Qui** : Direction, administrateur.

Menu « Journal » : toutes les actions importantes, avec leur auteur, leur date et le détail avant / après (créations, modifications, encaissements, annulations, réaffectations, validations…). La liste déroulante en haut filtre par type d'objet (bâtiment, bail, encaissement, compte…).

## 18. Questions fréquentes

**Je ne vois pas un menu dont un collègue parle.**
Les menus dépendent du profil. Demandez à l'administrateur le droit nécessaire.

**Le téléphone dit « Hors connexion » : ai-je perdu ma saisie ?**
Non. Elle est gardée dans le téléphone et part seule au retour du réseau. Le compteur en haut à droite le montre.

**Une saisie de terrain est en rouge, « Refusé ».**
L'agence l'a refusée pour la raison affichée (par exemple, un état des lieux déjà fait pour ce bail). Corrigez, ou supprimez-la.

**Le locataire dit ne pas avoir reçu son reçu.**
Vérifiez « Demandes » → « Messages à envoyer » : le message attend peut-être d'être envoyé. Vous pouvez aussi ouvrir la quittance depuis le lot et la lui remettre.

**Un encaissement a été saisi en double ou avec une erreur.**
Seule la Direction peut l'annuler, avec un motif (chapitre 7).

**Pourquoi un pointage de tournée est marqué « loin » ?**
Le téléphone était à plus de 250 m du bâtiment au moment du pointage. Ce n'est pas bloquant, mais le gestionnaire le voit.

**Le propriétaire ne trouve pas son mot de passe.**
L'administrateur lui donne un nouveau mot de passe provisoire : « Comptes » → son compte → « Réinitialiser ».

**Le devis ne peut pas être validé.**
Le propriétaire l'a refusé, ou son accord est attendu : regardez le motif dans la fiche de l'intervention.
